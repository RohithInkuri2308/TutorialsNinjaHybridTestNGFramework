📌 **Selenium Automation Framework – Hybrid (Java)**
📖 Project Overview

This project is a Hybrid Test Automation Framework developed using Selenium WebDriver with Java to automate the Login and Registration functionalities of a web application.

The framework follows industry best practices including Page Object Model (POM), data-driven configuration using properties files, cross-browser execution, and detailed HTML reporting using Extent Reports.

A dynamic email generation mechanism using timestamp-based logic is implemented to ensure unique registration during each test execution.

🛠 **Tech Stack**

Language: Java

Automation Tool: Selenium WebDriver

Framework: Hybrid Framework (POM + Utilities + Properties File)

Testing Framework: TestNG

Build Tool: Maven

Reporting: Extent Reports

Configuration Management: Properties File

Cross Browser Support: Chrome, Edge, FireFox

Version Control: GitHub

🏗 **Framework Architecture**

This Hybrid Framework combines:

Page Object Model (POM)

Properties file for storing login credentials & environment data

Utility classes for reusable functions

Base class for browser setup

Extent Reports integration

Cross-browser support using WebDriver setup

🔥 **Key Features**

Automated Login functionality

Automated Registration process

Dynamic email generation using current timestamp

Login credentials stored securely in properties file

Cross-browser execution support

Screenshot capture on failure

Extent Reports HTML report generation

Reusable utility methods
